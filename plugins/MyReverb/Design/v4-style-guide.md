# MyReverb - Style Guide v4

## Changes from v3
- Window **580 × 600 px**
- **Stereo VU:** two 234×118 needle meters (`wetMeterL`, `wetMeterR`) in one bezel
- Preview: L/R needles move slightly independently; WIDTH biases L vs R
- Red overload arc: `#9E2A32` fill at 30% opacity on scale
- Safe zone arc tint: `#5A8A62` at 12% opacity below −3 VU
